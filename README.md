
# TableBook - Restaurant Booking System

## Project Description
TableBook is a restaurant table booking website developed as part of my web development internship. It allows customers to register, log in, view table availability, book tables, and manage their bookings.

## Technologies Used
- HTML
- CSS
- JavaScript
- Browser LocalStorage

## Features
- Customer registration and login
- Admin login and dashboard
- Restaurant table availability
- Table booking and cancellation
- Customer booking history
- Registered customer list
- Booking search and CSV report export
- Responsive user interface

## Setup Instructions
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser, or use the VS Code Live Server extension.
4. Register a customer account and log in to test the booking features.

## Data Storage
This project uses browser LocalStorage to save customer and booking data in the current browser.
